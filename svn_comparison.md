1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

Git: ветка — просто указатель на коммит (файл ~41 байт), создаётся мгновенно, история общая.

SVN: ветка — копия директории в репозитории. Даже при «cheap copy» это отдельный путь, переключение идёт через сервер — отсюда «дорого».

2. Можно ли в SVN коммитить без интернета?
Нет. SVN централизован: коммит — транзакция на сервере. Без связи с сервером зафиксировать изменения нельзя (можно лишь сохранить diff в патч).

3. Когда SVN предпочтительнее Git?

Большие бинарные файлы (CAD, PSD, видео) + блокировки (svn:needs-lock).

Гранулярные права доступа по путям (authz) и централизованный аудит.

Частичный checkout (--depth) в огромных репозиториях.

Простота для нетехнических пользователей и дорогая миграция legacy-репозиториев.
